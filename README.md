# ENG: Analytics of marketing activity and audience dynamics for a mobile game
**Project objective:** to evaluate user base trends, player activity, financial results, and viral growth metrics.

**What's done:**

— Examination of the raw data and analysis of the number of users and game sessions. \
— Calculation of share of problematic sessions by device type and assessing potential causes for any anomalies. \
— Determinating the game’s virality coefficient and the projected average size of future user cohorts. \
— Analysis of revenue trends and the impact of a marketing campaign on financial performance. \
— Evaluating changes in key metrics (DAU, WAU, and MAU) as well as the relationships between them. \
— Calculation of the proportion of loyal users by testing various criteria for defining loyalty.

**Tools used:** PostgreSQL (CASE WHEN, aggregations, JOINs, CTEs/subqueries), Excel (post-processing, visualization).

**Result:** A presentation was prepared, featuring key findings and visualizations that demonstrate user activity trends and the impact of marketing factors on the game's revenue.

# RU: Аналитика маркетиноговой активности и динамики аудитории мобильной игры
**Цель проекта:** оценить динамику пользовательской базы, активность игроков, финансовые результаты и показатели вирусного роста.

**Что делала:**

— Изучила исходные данные и провёла анализ количества пользователей и игровых сессий.\
— Рассчитала долю проблемных сессий по типам устройств и оценил(а) возможные причины аномалий.\
— Определила коэффициент вирусности игры и средний размер будущих когорт пользователей.\
— Проанализировал(а) динамику выручки и влияние маркетинговой кампании на финансовые показатели.\
— Оценила изменения ключевых метрик DAU / WAU / MAU и их соотношение.\
— Рассчитала долю лояльных пользователей, протестировав разные критерии определения лояльности.

**Используемые инструменты:** PostgreSQL (CASE WHEN, агрегации, JOIN-ы, CTE/подзапросы), Excel (постобработка, визуализация).

**Результат:** подготовлена презентация с основными выводами и визуализациями, демонстрирующая динамику пользовательской активности и влияние маркетинговых факторов на выручку игры.
